DATASET DESCRIPTION

Daily weather observations

The project uses historical daily weather records for Khulna. The original file contained 14,610 rows and 9 columns, covering 1984 to 2023. Weather variables include rainfall, sunshine, humidity and temperature, along with station and calendar information.

RainfallSunshineHumidityTemperatureMonthDay of year

Dataset source: The project notebook describes the data as historical Khulna weather records attributed to the Bangladesh Meteorological Department and distributed through Mendeley Data. Add the exact dataset URL to the report if required.

PREDICTION TARGET

Will it rain tomorrow?

The target was created by shifting the rainfall column by one day. The following day's rainfall was converted into a binary class:

0No Rain10,073 records68.95%
1Rain4,536 records31.05%

A value greater than zero means Rain (1); zero rainfall means No Rain (0). The final row is removed because it has no following-day rainfall value.

DATA PREPARATION & JUSTIFICATION

How the data was prepared

01Cleaned columns

Removed the unnecessary Unnamed index column. The dataset had no missing values or duplicate rows.

02Created date

Combined Year, Month and Day into a date field, then sorted observations chronologically.

03Created target

Shifted rainfall to represent the following day and converted it into Rain / No Rain classes.

04Selected features

Used Rainfall, Sunshine, Humidity, Temperature, Month and DayOfYear. Station was constant and Year was not used as a direct input.

05Split by time

Used the first 80% for training (11,687 rows) and the final 20% for testing (2,922 rows).

06Prevented time leakage

Kept the split chronological rather than random, so the test period comes after the training period.

EXPLORATORY DATA ANALYSIS

Patterns found in the weather data

01Seasonal rainfall

Average rainfall was highest around July, while November, December and January were comparatively dry.

02Humidity matters

Humidity had a positive relationship with the next-day rainfall target in the correlation analysis.

03Sunshine pattern

Sunshine showed a negative relationship with rainfall; rainy conditions were generally associated with less sunshine.

04Unequal classes

No Rain represented 68.95% of records and Rain represented 31.05%, so class-aware metrics were included.

02 / MODEL DESIGN

Why these machine learning models?

Four classification algorithms were trained and evaluated on the same chronological split.

01

Logistic Regression

A classification baseline. Feature scaling was applied, and balanced class weights were used to account for the unequal class distribution.

Median imputation · StandardScaler · balanced weights
02

Decision Tree

A tree-based model that learns rule-like splits between weather conditions. It can capture non-linear patterns and is relatively easy to interpret.

Median imputation · balanced weights
03

Random Forest SELECTED

An ensemble of decision trees. It was selected because it achieved the strongest accuracy, precision, ROC-AUC and Average Precision in this evaluation.

200 trees · balanced weights · random_state 42
04

K-Nearest Neighbors

A distance-based classifier. Standardization was applied because KNN uses distances and features on larger scales could otherwise dominate.

Median imputation · StandardScaler · 5 neighbors
